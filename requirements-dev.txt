# requirements-dev.txt — tooling for the test/lint layers. NONE of this is
# needed to RUN the gateway; it is deliberately kept out of
# requirements.txt / requirements.lock so a production install stays lean
# and `./setup.sh` does not pull a browser engine.
#
#     .venv/bin/pip install -r requirements-dev.txt
#     .venv/bin/playwright install chromium webkit    # one-time, after the above
#
# Which layer needs what — see CLAUDE.md → "Running Tests":
#
#   ruff      → the T0.LINT gate in `tests/run_all.py --offline`. Config
#               lives in pyproject.toml and is held at ZERO violations.
#               Absent → the gate SKIPS (never fails a clean clone).
#   pytest    → tests/frontend (the Playwright UI suite). The behavioural
#     +         unit tests under tests/test_*.py are stdlib `unittest` and
#   playwright  need none of this.
#   selenium  → tests/frontend/safari_smoke.py (real Safari, opt-in;
#               also needs `safaridriver --enable`).
#   Appium    → tests/frontend/ios_sim_smoke.py (iOS Simulator, opt-in;
#               also needs a running `appium` server + a booted sim).
#
# Pinned like requirements.lock: a Playwright minor bump can change
# selector/timing behaviour and turn the UI suite red for reasons that
# have nothing to do with the gateway.
