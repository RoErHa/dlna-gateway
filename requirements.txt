Pillow>=10.0

# ── 2.0 transport refresh — ASGI app server ───────────────────
# NOT optional. The gateway IS `dlna_asgi:app` served by Hypercorn; the
# stdlib BaseHTTPRequestHandler edge these once merely supplemented was
# removed in Cleanup C, so without these there is no server at all.
# See docs/BUILDING_2.0.md.
#
# UPPER BOUNDS: these own the entire TLS/HTTP-2 edge, so an unbounded
# `>=` would let a future major silently replace the server on a fresh
# `./setup.sh`. Caps are on the MAJOR only — minors still float here;
# requirements.lock is what pins exactly.
fastapi>=0.110.0,<1.0
hypercorn>=0.16.0,<1.0

# Declared explicitly because we IMPORT IT DIRECTLY (module scope, in 9
# dlna_asgi_*.py modules: run_in_threadpool + the Response classes), not
# merely through FastAPI. FastAPI happens to require it today
# (`starlette>=0.46.0`), but a dep we import by name belongs in the spec —
# otherwise a future FastAPI that vendored or dropped it would install
# cleanly and leave the gateway unable to start.
starlette>=0.46,<2.0
#
# anyio is deliberately NOT pinned here: the single use
# (dlna_asgi raising the threadpool limiter 40 → 256) is inside a
# try/except that logs and carries on, and it arrives via fastapi+hypercorn.

# ── beets enrichment toolchain (NOT pip deps of this venv) ────
# beets (tools/beets_enrich.py) runs in its OWN Homebrew keg venv, not
# this one — install it with brew, NOT pip (`pip3 install beets` gets
# wiped by every Homebrew python upgrade; that killed the 2026-06 install):
#
#   brew install chromaprint beets
#
# The formula ships WITHOUT two plugin deps the enrichment workflow
# needs (musicbrainzngs for the MB metadata source, pyacoustid for
# chroma fingerprinting). Install them into the keg's venv — and
# RE-RUN THIS after any `brew upgrade beets` (keg is replaced):
#
#   BEETS_KEG=$(brew --prefix beets)/libexec
#   $BEETS_KEG/bin/python -m pip install --prefix $BEETS_KEG \
#       musicbrainzngs pyacoustid
#
# tools/beets_enrich.py checks both at start and prints this exact fix
# if they're missing.

# ── Pinning model ─────────────────────────────────────────────
# THIS file is the SPEC: loose ranges. Everything EXCEPT the ASGI trio
# (fastapi / starlette / hypercorn) is optional and degrades gracefully
# when missing; those three are hard requirements to serve at all.
# `requirements.lock` is the INSTALL: the exact transitive closure of
# the above, ==-pinned, regenerated by `python3 tools/regen_lock.py`
# and kept honest by `tests/test_lock_sync.py`. Use the lock for a
# reproducible / production install; use this file to deliberately
# test newer upstreams.
# Dev/test tooling (ruff, pytest, playwright, …) is in
# `requirements-dev.txt` and is NOT required to run the gateway.
